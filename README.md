# 终末地 CAFE · 反馈与建议

这里收集[终末地工具台](https://endfield.linbin.org/)的问题反馈与功能建议。

[提交反馈](https://github.com/linbin0721/Endfield-cafe-feedback/issues/new/choose) · [查看已有问题](https://github.com/linbin0721/Endfield-cafe-feedback/issues)

请选择“识别 / 求解问题”“网站问题”或“功能建议”。只需填写问题说明；题号、截图、复现步骤和设备信息均可按需补充。提交需要登录 GitHub，可使用中文、English、日本語或한국어。

Issue 和附件公开可见。上传截图前，请遮住玩家 UID、账号、聊天等个人信息；请勿粘贴密码、密钥或其他私密资料。网站中的截图预览不会自动附加到反馈中。

本仓库用于反馈与讨论，包含说明和 Issue 模板。

---

This repository collects bug reports and feature requests for [Endfield Workbench](https://endfield.linbin.org/).

[Open a report](https://github.com/linbin0721/Endfield-cafe-feedback/issues/new/choose) or [browse existing issues](https://github.com/linbin0721/Endfield-cafe-feedback/issues). Choose a recognition/solver issue, a website issue, or a feature request. Only the description is required; other details and screenshots are optional. A GitHub account is required to submit an issue. Reports in Chinese, English, Japanese, and Korean are welcome.

Issues and attachments are public. Hide personal information before attaching screenshots, and never post passwords or keys. The website does not attach your selected screenshot automatically.
