# 终末地 CAFE · 反馈与建议

这里收集[终末地工具台](https://endfield.cafe/zh-CN/)的问题反馈与功能建议。

[提交反馈](https://github.com/linbin0721/Endfield-cafe-feedback/issues/new/choose) · [查看已有问题](https://github.com/linbin0721/Endfield-cafe-feedback/issues) · [邮件联系](mailto:feedback@endfield.cafe)

请选择“识别 / 求解问题”“网站问题”或“功能建议”。只需填写问题说明；题号、截图、复现步骤和设备信息均可按需补充。提交需要登录 GitHub，可使用中文、English、日本語或한국어。

Issue 和附件公开可见。上传截图前，请遮住玩家 UID、账号、聊天等个人信息；请勿粘贴密码、密钥或其他私密资料。网站中的截图预览不会自动附加到反馈中。

本仓库用于反馈与讨论，包含说明和 Issue 模板。

不方便使用 GitHub 时，可以通过上面的邮箱联系。来信会转到项目专用邮箱，回复来自 `endfieldcafe@163.com`。

## 使用范围与图片处理

- 当前识别只针对简体中文游戏截图验证；界面支持简中、英文、日文和韩文，不代表已支持对应语言截图。照片识别功能尚未开放。
- 题库尚未完善，建议优先使用截图识别；题号查询只能找到已收录的题面。
- 选图和裁剪在浏览器本地完成，点击“识别并求解”后才上传当前预览的图片。服务器临时处理图片，不持久保存上传原图。
- 符合条件的题号、题面及图像摘要会记入题库，供后续查询与复用。识别上传与反馈附图是两个独立操作。
