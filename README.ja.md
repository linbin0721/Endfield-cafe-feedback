# エンドフィールド CAFE · フィードバックと提案

[Endfield Workbench](https://endfield.cafe/ja/)の不具合報告と機能の提案を受け付けるリポジトリです。

[フィードバックを送る](https://github.com/linbin0721/Endfield-cafe-feedback/issues/new/choose) · [既存の Issue を見る](https://github.com/linbin0721/Endfield-cafe-feedback/issues) · [メールで問い合わせる](mailto:feedback@endfield.cafe)

「画像認識・パズル求解の問題」「サイトの問題」「機能の提案」から選んでください。必須なのは内容の説明だけです。問題番号、スクリーンショット、再現手順、端末情報は必要に応じて追加できます。投稿には GitHub へのログインが必要です。中国語・英語・日本語・韓国語での投稿を歓迎します。

Issue と添付ファイルは公開されます。画像を添付する前に、プレイヤー UID、アカウント情報、チャットなどの個人情報を隠してください。パスワードや鍵などの非公開情報は投稿しないでください。サイトで選択したスクリーンショットが自動的に添付されることはありません。

このリポジトリはフィードバックと意見交換のためのもので、案内と Issue テンプレートを掲載しています。

GitHub アカウントがなくても、上のメールリンクから問い合わせできます。メールは専用の受信箱に転送され、返信は `endfieldcafe@163.com` から届きます。

## 対応する画像と画像の取り扱い

- 現在、認識を検証しているのは簡体字中国語版ゲームのスクリーンショットのみです。画面は中国語・英語・日本語・韓国語に対応していますが、各言語のスクリーンショット認識への対応を意味するものではありません。写真の認識機能はまだ公開していません。
- 問題データベースはまだ整備中です。まずはスクリーンショットによる認識をおすすめします。問題番号で検索できるのは登録済みの問題だけです。
- 画像の選択と切り抜きはブラウザー内で行います。「認識して解く」を押したときに、プレビュー中の画像をアップロードします。サーバーでは画像を一時的に処理し、アップロードされた元画像を永続保存しません。
- 条件を満たした問題番号・盤面情報・画像のハッシュ値は、後の検索と再利用のためにデータベースへ保存します。認識用にアップロードした画像が、問い合わせに自動添付されることはありません。
