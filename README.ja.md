# エンドフィールド CAFE · フィードバックと提案

[Endfield Workbench](https://endfield.cafe/ja/)の不具合報告と機能の提案を受け付けるリポジトリです。

次の2つの方法でフィードバックを送れます。

- [GitHub でのフィードバック（公開）](https://github.com/linbin0721/Endfield-cafe-feedback/issues/new/choose)
- [メールでのフィードバック：feedback@endfield.cafe](mailto:feedback@endfield.cafe)

[既存の Issue を見る](https://github.com/linbin0721/Endfield-cafe-feedback/issues)

「画像認識・パズル求解の問題」「サイトの問題」「機能の提案」から選んでください。必須なのは内容の説明だけです。問題番号、スクリーンショット、再現手順、端末情報は必要に応じて追加できます。投稿には GitHub へのログインが必要です。中国語・英語・日本語・韓国語での投稿を歓迎します。

Issue と添付ファイルは公開されます。パスワードや鍵などの非公開情報は投稿しないでください。サイトで選択したスクリーンショットが自動的に添付されることはありません。

このリポジトリはフィードバックと意見交換のためのもので、案内と Issue テンプレートを掲載しています。

GitHub アカウントがなくても、上のメールリンクから問い合わせできます。メールは専用の受信箱に転送され、返信は `endfieldcafe@163.com` から届きます。

## 対応する画像と画像の取り扱い

- 現在、認識を検証しているのは簡体字中国語版ゲームのスクリーンショットのみです。画面は中国語・英語・日本語・韓国語に対応していますが、各言語のスクリーンショット認識への対応を意味するものではありません。写真の認識機能はまだ公開していません。
- 問題データベースはまだ整備中です。まずはスクリーンショットによる認識をおすすめします。問題番号で検索できるのは登録済みの問題だけです。
- 画像の選択と切り抜きはブラウザー内で行います。「認識して解く」を押したときに、プレビュー中の画像をアップロードします。
- 本サイトはプレイヤーのアカウント情報を収集せず、プレイヤーごとのプロフィールも作成しません。スクリーンショットはパズル認識にのみ使用し、元画像は永続保存しません。問題データベースに保存するのは問題番号・盤面情報・画像のハッシュ値のみで、プレイヤー UID・ニックネーム・チャット履歴は保存しません。
- 認識用にアップロードした画像が、問い合わせに自動添付されることはありません。
