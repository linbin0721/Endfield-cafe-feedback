# 엔드필드.café · 피드백 및 제안

[엔드필드.café](https://endfield.cafe/ko/)의 문제 제보와 기능 제안을 받는 저장소입니다.

다음 두 가지 방법으로 피드백을 보낼 수 있습니다.

- [GitHub 피드백 (공개)](https://github.com/linbin0721/Endfield-cafe-feedback/issues/new/choose)
- [이메일 피드백: feedback@endfield.cafe](mailto:feedback@endfield.cafe)

[기존 이슈 보기](https://github.com/linbin0721/Endfield-cafe-feedback/issues)

‘이미지 인식·퍼즐 풀이 문제’, ‘웹사이트 문제’, ‘기능 제안’ 중에서 선택해 주세요. 내용 설명만 필수이며, 문제 번호, 스크린샷, 재현 방법, 기기 정보는 필요에 따라 추가할 수 있습니다. 이슈를 등록하려면 GitHub에 로그인해야 합니다. 중국어, 영어, 일본어, 한국어로 작성할 수 있습니다.

이슈와 첨부 파일은 공개됩니다. 비밀번호, 키 또는 기타 비공개 정보는 게시하지 마세요. 웹사이트에서 선택한 스크린샷은 자동으로 첨부되지 않습니다.

이 저장소는 피드백과 의견 교환을 위한 공간이며, 안내와 이슈 템플릿을 제공합니다.

GitHub 계정이 없어도 위 이메일 링크로 문의할 수 있습니다. 메일은 프로젝트 전용 메일함으로 전달되며, 답장은 `endfieldcafe@163.com`에서 발송됩니다.

## 지원 이미지 및 이미지 처리

- 현재 인식 검증은 중국어 간체 게임 스크린샷만을 대상으로 합니다. 중국어·영어·일본어·한국어 인터페이스를 제공하지만, 해당 언어의 스크린샷 인식을 모두 지원한다는 뜻은 아닙니다. 사진 인식 기능은 아직 공개하지 않았습니다.
- 퍼즐 데이터베이스는 아직 구축 중입니다. 스크린샷 인식을 먼저 이용하는 것을 권장합니다. 문제 번호로는 이미 등록된 퍼즐만 조회할 수 있습니다.
- 이미지 선택과 자르기는 브라우저 안에서 처리합니다. “인식 및 풀이”를 누를 때만 현재 미리보기 이미지가 업로드됩니다.
- 이 사이트는 플레이어 계정 정보를 수집하거나 플레이어별 프로필을 만들지 않습니다. 스크린샷은 퍼즐 인식에만 사용하며 원본 이미지는 영구 저장하지 않습니다. 퍼즐 데이터베이스에는 문제 번호, 퍼즐 정보 및 이미지 해시만 보관하며, 플레이어 UID, 닉네임 또는 채팅 기록은 저장하지 않습니다.
- 인식용 이미지 업로드와 문의용 이미지 첨부는 별개의 작업입니다.
