# 엔드필드 CAFE · 피드백 및 제안

[Endfield Workbench](https://endfield.cafe/ko/)의 문제 제보와 기능 제안을 받는 저장소입니다.

[피드백 보내기](https://github.com/linbin0721/Endfield-cafe-feedback/issues/new/choose) · [기존 이슈 보기](https://github.com/linbin0721/Endfield-cafe-feedback/issues)

‘이미지 인식·퍼즐 풀이 문제’, ‘웹사이트 문제’, ‘기능 제안’ 중에서 선택해 주세요. 내용 설명만 필수이며, 문제 번호, 스크린샷, 재현 방법, 기기 정보는 필요에 따라 추가할 수 있습니다. 이슈를 등록하려면 GitHub에 로그인해야 합니다. 중국어, 영어, 일본어, 한국어로 작성할 수 있습니다.

이슈와 첨부 파일은 공개됩니다. 스크린샷을 첨부하기 전에 플레이어 UID, 계정 정보, 채팅 등 개인 정보를 가려 주세요. 비밀번호, 키 또는 기타 비공개 정보는 게시하지 마세요. 웹사이트에서 선택한 스크린샷은 자동으로 첨부되지 않습니다.

이 저장소는 피드백과 의견 교환을 위한 공간이며, 안내와 이슈 템플릿을 제공합니다.
