# Endfield CAFE · Feedback and suggestions

This repository collects bug reports and feature requests for [Endfield Workbench](https://endfield.cafe/en/).

[Submit feedback](https://github.com/linbin0721/Endfield-cafe-feedback/issues/new/choose) · [Browse existing issues](https://github.com/linbin0721/Endfield-cafe-feedback/issues) · [Contact by email](mailto:feedback@endfield.cafe)

Choose a recognition/solver issue, a website issue, or a feature request. Only the description is required; the question code, screenshots, steps to reproduce, and device information are optional. A GitHub account is required to submit an issue. Reports in Chinese, English, Japanese, and Korean are welcome.

Issues and attachments are public. Hide player UIDs, account details, chat messages, and other personal information before attaching screenshots. Never post passwords, keys, or other private information. The website does not automatically attach the screenshot you selected.

This repository is for feedback and discussion and contains guidance and issue templates.

You can use the email link above without a GitHub account. Messages are forwarded to the project mailbox; replies come from `endfieldcafe@163.com`.

## Supported inputs and image handling

- Recognition is currently validated only for screenshots of the game in Simplified Chinese. The Chinese, English, Japanese, and Korean interface options do not imply recognition support for screenshots in those languages. Photo recognition is not available yet.
- The puzzle catalog is incomplete. We recommend screenshot recognition first; code lookup only finds puzzles already in the catalog.
- Image selection and cropping happen locally in your browser. The current preview is uploaded only when you click “Recognize and solve”. The server processes the image temporarily and does not persist the uploaded original.
- Eligible puzzle codes, puzzle layouts, and image hashes are saved in the catalog for later lookup and reuse. Uploading an image for recognition does not attach it to a feedback message.
